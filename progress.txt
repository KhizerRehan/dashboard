KUBEVIRT PRESET SPREAD SYNTAX ERROR - FIX TRACKING
================================================================================
Date: January 21, 2026
Issue: Spread syntax Symbol.iterator error in kubevirt credential selection
Root Cause: presetList.items was undefined/null when spread operator used

================================================================================
🎯 ROOT CAUSE IDENTIFIED!
================================================================================

**ERROR LOCATION:** HTTP Headers processing in Angular's HttpClient
**REQUEST:** GET /api/v2/projects/{projectId}/providers/kubevirt/subnets
**FAILURE POINT:** _HttpHeaders.applyUpdate() - when setting Authorization header

**Stack Trace:**
  at _HttpHeaders.applyUpdate (module.mjs:235:14)
  at module.mjs:203:48
  at Array.forEach (<anonymous>)
  at _HttpHeaders.init (module.mjs:203:25)
  at _HttpHeaders.forEach (module.mjs:278:10)

**Root Cause Analysis:**
The spread syntax error occurs in Angular's HTTP module when processing headers.
This happens when req.headers (HttpHeaders object) is being cloned/spread but
contains non-iterable data, likely due to corrupted headers state or invalid
Authorization token format.

**Likely Causes:**
1. req.headers.keys() returning non-iterable value
2. Authorization token is malformed or undefined
3. HttpHeaders internal state is corrupted
4. Headers being set with spread on non-iterable object
